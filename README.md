# seed-service

Учебный сервис-«зерно» для курса **«Дорога в прод»** (внедрение и поддержка компьютерных систем).

Это намеренно крошечный API на FastAPI. Он здесь не для того, чтобы им восхищаться, — а для того, чтобы весь курс мы упаковывали его, деплоили, ломали и чинили. Приложение простое, вся сложность будет в том, что мы делаем *вокруг* него.

## Что внутри

```
seed-service/
├── main.py          # сам сервис: два эндпоинта
├── pyproject.toml   # объявление проекта: зависимости и версия Python
├── uv.lock          # точные версии всех библиотек (ведёт uv)
├── .gitignore
└── README.md
```

Сервис читает приветствие из переменной окружения `GREETING` и отдаёт два эндпоинта:

- `GET /` → `{"message": "<ваше приветствие>"}`
- `GET /health` → `{"status": "ok"}` — «я жив» (пригодится дальше в курсе)

## Что нужно поставить заранее

- [uv](https://docs.astral.sh/uv/) — менеджер пакетов и окружений для Python;
- git.

Саму версию Python отдельно ставить не нужно — при необходимости uv скачает её сам.

## Как запустить (happy path)

> [!tip]
> На занятии сначала попробуйте запустить сервис **не заглядывая сюда** — так вы своими глазами увидите, на какие «грабли» он опирается. А уже потом сверьтесь с этим разделом.

**1. Подготовить окружение.** Одна команда ставит нужную версию Python и точные версии библиотек в изолированное окружение `.venv`:

```bash
uv sync
```

**2. Запустить сервис, задав приветствие.**

macOS / Linux:

```bash
GREETING="Привет, прод!" uv run uvicorn main:app
```

Windows (PowerShell):

```powershell
$env:GREETING = "Привет, прод!"; uv run uvicorn main:app
```

**3. Проверить.** Откройте в браузере:

- <http://127.0.0.1:8000/> — приветствие;
- <http://127.0.0.1:8000/health> — `{"status":"ok"}`.

Остановить сервис — `Ctrl+C`.

## Грабли (это специально)

Сервис держится на нескольких скрытых **предположениях об окружении**. Если какое-то из них не выполнено, вы получите честную ошибку. Это не поломка — это учебный материал.

| Что нарушено | Что увидите | Почему |
|---|---|---|
| Библиотеки не установлены (запуск в обход uv) | `ModuleNotFoundError: No module named 'fastapi'` | Код опирается на `fastapi` и `uvicorn`, а их на чистой машине нет. Лечит `uv sync`. |
| Не задана переменная `GREETING` | `KeyError: 'GREETING'` (при старте) | Сервис читает настройку из окружения. Нет настройки — нет старта. |
| Другая версия Python у коллеги | `SyntaxError` или несовместимость | Проект требует Python `>=3.12` (см. `pyproject.toml`). |

Дальше в курсе мы научимся перевозить все эти предположения вместе с кодом, чтобы «работает у меня» превратилось в «работает у всех».

## Полезные команды uv

```bash
uv sync                # собрать окружение по pyproject.toml + uv.lock
uv run <команда>       # выполнить команду в окружении проекта
uv add <пакет>         # добавить зависимость (обновит pyproject.toml и uv.lock)
```
